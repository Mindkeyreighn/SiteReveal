SITEREVEAL — GLOBAL POSITIONING + STRIPE BRANDING UPDATE
July 30, 2026

UPLOAD

1. Open the existing SiteReveal GitHub repository.
2. Upload everything inside this package at the repository root.
3. Allow GitHub to replace the existing index.html.
4. Preserve the assets folder structure so the logo remains located at:
   assets/sitereveal-logo.png
5. Commit the upload and allow the connected Vercel project to redeploy.

This version includes every previous SiteReveal storefront, Admin-link,
“Already Done,” Website at Work, and official-logo improvement.

The four primary storefront headings now use the clean Inter type family:

- Your website is already built.
- Real sites. Different industries.
- Your business should keep working—even when you aren’t.
- Browse available websites.

Their established sizes, colors, positions, and responsive behavior remain
unchanged.

The “Your business should keep working” heading now uses a comma instead of
an em dash, removing the distracting horizontal-bar effect while preserving
the original message and layout.

The “North Idaho & Spokane Valley” hero label has been removed so SiteReveal
does not appear limited to those two markets.

STRIPE BRANDING

The Stripe-ready horizontal logo is:
assets/stripe-checkout-logo.png

In Stripe Dashboard, open Settings > Branding, upload this file as the Logo,
preview the customer-facing checkout appearance, and save the changes.

No Supabase, database, admin, checkout, or Vercel environment-variable change
is required.
