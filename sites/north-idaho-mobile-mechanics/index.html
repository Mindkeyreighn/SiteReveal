Field triage board

What stopped the work?

Use the closest starting point when you call. This is a conversation guide—not a diagnosis—and service suitability must be confirmed directly.

01 / NO START

It will not turn over or run

Share what happens at the key or switch, recent battery activity, warning lights, and last known operation.

START WITH: MOBILE DIAGNOSIS
02 / LEAK

Fluid is visible

Note fluid color, approximate location, rate of loss, and whether the machine can be shut down safely.

START WITH: SAFETY + LOCATION
03 / PERFORMANCE

Power, sound, or heat changed

Describe when it happens, load conditions, gauges, smells, sounds, and any recent repair work.

START WITH: OPERATING SYMPTOMS
04 / MAINTENANCE

Keep downtime from starting

Provide equipment identity, hours or mileage, maintenance history, and the work environment.
